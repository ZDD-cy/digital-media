# 第一人称工作台与选版

保留工程原有的第一人称 GameMode、PlayerController 和 Character。在关卡中放置 `IndigoWorkbenchBridge`，指定 Director 和工作台 CameraActor。Bridge 的位置是靠近检测中心，默认检测半径 350 厘米，可在实例上修改。

运行时，靠近后按 E 进入工作台，显示鼠标并暂时阻止角色移动、转头；再次按 E 或点击退出按钮恢复角色镜头和输入。此功能只面向本地单人玩家 0。

先点击“查看布料”和“查看订单”，然后将 A/B/C 拖到左右槽。同款可同时用于左右两边，拖动后样本回到来源位置。右键取消拖动。界面显示共享结果，可清空、交换、确认。确认要求两侧都有花版，确认后进入 Fold 状态。

## 花版来源

以 `IndigoPatternSource` 为父类建立三个蓝图。分别设置 Pattern 为 A、B、C，BoardMesh 设置为花版静态网格体。该类自带点击碰撞框和字母标识，Kind 为 DragSource，DragGroup 为 Pattern，ActiveStep 为 Select。VisualScale 调整样本大小。

左右槽使用 `IndigoInteractable`，Kind 为 DropTarget，DragGroup 为 Pattern，ActiveStep 为 Select，LeftSlot 分别为 true 和 false。

## 当前 LanRan 工程中的对象

- `PatternSource_A/B/C`，蓝图位于 `/Game/Characters/Mannequins/interact/BP_PatternSource_A/B/C`。
- `leftboard_Slot`、`rightboard_Slot` 跟随原有板子组件。
- `Indigo_Workbench` 以现有 BP_WorkbenchTrigger 位置为检测中心，半径 400 厘米。
- `CAM_IndigoSelection` 为新增的选版机位。

A/B/C 暂时复用原有板子模型，以字母区分逻辑款式。正式的三种雕花外观、布面纹理与结果材质需要后续替换、挂接。

## 折布与夹版演示

确认花版后，界面切换到折布操作。点击“沿当前折线折布”依次完成三折；每一折结束后才增加进度并开放下一次操作。然后按“放布 → 合版 → 分别扣左右夹具”操作，两侧都扣好才进入 Dye。夹具左右先后不限，同一侧不能重复扣。

`Indigo_CraftPreview` 是本关卡新增的 `IndigoCraftPreview` 原生实例，使用方块布料、木版和夹具演示流程。蓝色线标出当前折线。演示时隐藏选择样本和原板子的可见模型；重新开始时恢复。原模型蓝图及其内部自主动画未改写。

配置方式：把实例的 Flow 指向 Director.Flow，并把实例加入 Flow.VisualTargets；本演示设 FoldCount=3、MotionSeconds=1.2、UsePlaceholderTimer=false。每段动作结束时，演示 Actor 使用当初收到的 Token 调用 CompleteAnimation；流程由完成回调推进。重新开始会停止当前演示、废弃旧 Token，并复位布料、木版、夹具和花版结果。

此演示 Actor 处理 Fold、PlaceCloth、ClosePlate、ClampLeft、ClampRight、Dye 动画请求。接正式动画时，移除该演示 Actor 的 VisualTargets 引用，由正式动画 Actor 接收 PlayIndigoAnimation，并在结束时回传原 Token；不要同时保留两个完成回调来源。

按 E 或“返回行走 E”可离开工作台，制作进度保留。动画期间离开时动作仍会完成，重新进入后显示当前进度。“重新开始”可在动作中使用，会清空本局。

源代码包不包含 LanRan 的美术资产和关卡。当前工程中的上述实例已经单独保存。

## 四档染色演示

两侧夹具都扣紧后，面板显示染色深度 0/4。点击“浸染一档 / 继续染色”，演示夹版抬起、移入预览染缸、下浸、出缸显色并返回工作台。默认一段 4 秒，完整结束后深度才加一。动作中不可继续或收工；深度为 0 不允许收工；1～3 档可继续或收工；第 4 档禁用继续。收工进入 Wash，结果保留，清洗和展开界面尚待接入。

`IndigoCraftPreview.DyeSeconds` 设置染色演示时长。布料和色样材质都需要名为 `DyeColor` 的向量参数；本关卡 `/Game/Core/IndigoPreview/M_DyeCloth` 与 `/Game/Core/IndigoPreview/M_DyeSwatch` 已接好。色样使用 Unlit 材质以减小场景强光的影响，布料与色样接收同一份颜色数据。SetDyeProgress 接收已完成深度与当前段进度，颜色在浅蓝至深靛四档间逐步加深；Restart 将动态材质、档位和入缸位置一并复位。原生类只提供参数调用，不自带项目材质资产。

本机新增 `Indigo_WorkbenchPlatform` 作为可行走的工作台木平台，并将两个 PlayerStart 放到平台上；原位置下方没有支撑，角色会落到下方地面。此地图配置不包含在源码 ZIP 中。
