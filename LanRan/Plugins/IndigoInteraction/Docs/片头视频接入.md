# 游戏片头视频接口 · 2.1.0

片头和寄件后的两段地域短片相互独立。地域短片仍按用户要求留空。

## 接入现有 LanRan 关卡

1. 将正式视频放到工程 `Content/Movies/Opening.mp4`。推荐使用目标电脑能够解码的 H.264 MP4，并在交付电脑复测。
2. 在内容浏览器新建 **媒体 → 文件媒体源（File Media Source）**，命名 `MS_Opening`，文件路径指向该视频。将视频放在 Movies 内，避免使用个人电脑的绝对路径。
3. 选中关卡里的 `Indigo_Workbench`，在细节中展开原生组件 **OpeningVideo**，将 **Video Source** 指定为 `MS_Opening`，保留 **Play On Start** 勾选。
4. 保存关卡并运行。组件自动创建 Media Player、Media Texture、声音组件和全屏等比视频界面，无须另建播放器或视频材质。
5. 正式视频到位后重新打包并确认 `Content/Movies` 中的视频被包含；不能只替换源码 ZIP。当前交付版未配置正式片头，直接进入第一人称。

## 蓝图接口

- `Play Opening Video()`：手动开始播放；没有媒体源、已经播放或正在工作台操作时返回 false。
- `Skip Opening Video()`：结束片头；按钮“跳过片头”已接入此函数。
- `On Opening Finished(Result)`：结果为 Completed、Skipped 或 Failed，可绑定淡入、字幕或后续逻辑。
- `Get Video Texture()`：供自定义界面取用当前视频纹理。
- `Open Timeout Seconds`：默认 15 秒。打开失败或超时会移除片头界面，恢复角色移动、视角及鼠标状态。

片头只在关卡启动且配置了媒体源时自动播放；游戏内“重新开始”只重置制作流程，不重播片头。没有配置视频不会出现空白等待页。

## 技术栈

UE 5.8.3；C++ Runtime 插件与蓝图；UMG/Slate；CameraActor；交互 BoxComponent 与射线拾取；动态材质和现有组合贴图；MediaAssets（MediaPlayer / MediaTexture / MediaSoundComponent）。Windows 构建使用 UBT/UAT。Git/LFS 保存源码和二进制资源。Python 仅用于编辑器配置及验收。
