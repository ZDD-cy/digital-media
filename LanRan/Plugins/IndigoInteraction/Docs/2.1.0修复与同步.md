# 场景、布面、拖放修复与片头接口

日期：2026-10-19。工程：LanRan；引擎：UE 5.8.3；插件：2.1.0。

## 修复内容

- 当前 qingdeng 关卡缺少 Landscape 对象；从本机缓存的原始 main 关卡提取原地形，保存为 `L_RestoredTerrain`，作为工作关卡的 Always Loaded 子关卡。保留当前角色和交互配置。
- 增加独立工作台，重新排列左右选版板、ABC 源、布料、制作区和机位，避免与原染缸重叠；保留原移动板蓝图，选版使用稳定板面。
- 投放框按真实网格包围盒中心、旋转和缩放对齐，并随组件移动更新。工作台拾取直接检测当前可用交互框，普通模型不会再挡住板面或绿色制作目标。
- 制作目标的判定框覆盖整个可见绿色区域，并提供少量边缘余量。无效投放仍复位，不跳过步骤。
- 迁入仓库已有的组合贴图，接入 AA、AB、AC、BA、BB、BC、CA、CB、CC 各五档，共 45 张；展开时按同一 Left/Right/Depth 结果选图。不补画或改绘原花纹。折布几何动作仍是程序预览。
- 新增可选的游戏开头视频组件，支持画面、声音、播放结束回调、跳过和打开失败回退；当前正式关卡媒体源为空。地域短片仍留空。

## 同步到同伴电脑

只同步插件源码不能带走关卡和纹理修复。资源补丁 `LanRan_2.1.0_ResourcePatch.zip` 包含以下内容：

- `LanRan/Content/Japanese_Village/Levels/L_TestLight.umap`
- `LanRan/Content/Japanese_Village/Levels/L_RestoredTerrain.umap`
- `LanRan/Content/Indigo/Textures/`
- `LanRan/Content/Core/IndigoPreview/M_ExistingPatternCloth.uasset`
- `LanRan/Plugins/IndigoInteraction` 的源码、描述文件和说明

关闭 UE 后先备份本地关卡，再将补丁解压到包含 LanRan 文件夹的仓库根目录，保持上述目录层级。重新编译 Development Editor，再打开 L_TestLight。补丁只包含本轮新增或修改的资源，仍依赖原仓库中的场景、模型和角色。

通过 Git 同步时，需要提交上述源码、关卡、材质和贴图，并确保接收端完成 Git LFS 下载；`.uasset/.umap` 不能停留为几行 LFS 指针文本。本轮未自动提交或推送到远端。
