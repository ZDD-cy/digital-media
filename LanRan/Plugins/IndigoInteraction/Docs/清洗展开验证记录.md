# 2026-10-17 清洗、展开与回看验证记录

环境：UE 5.8.3，Windows，LanRan/L_TestLight，插件 1.4.0。此记录更新 1.3.0 中“尚未接入清洗展开”的状态。

## 实现

工作台收工后，按“清洗 → 提起沥水 → 分别松开左右夹具 → 展开作品”操作。左右松夹先后不限，单侧松开不能展开。演示夹版进入清水盆、提出、夹具移开、木版打开，布料分三段恢复尺寸；结束回传原 Token 后进入 Reveal。交付使用独立完成回调，完成页可回看、返回或重新开始；作品可停留欣赏，不会自动交付。

ShowFinalQuilt 从共享 Result 读取 Left、Right、Depth，写入 DisplayedResult，并向动态布面材质写 PatternLeft、PatternRight、ShowPattern 与 DyeColor。本机 M_FinalCloth 使用菱形、方格、圆环三种几何纹样区分 A/B/C；展示朝向按本工作台机位校正。正式雕花与中央旧样遮罩仍待美术替换。

## 验证

- Development Editor / Win64 和 Development Game / Win64 构建链接成功。
- 五项自动化检查通过，失败 0；新增 Indigo.Workbench.WashRevealCallbacks，验证一档、四档两局、未清洗/沥水不能跳步、单侧松夹不能展开、动画中连点、重复回调、清洗中重开、回看保留结果与重开复位。
- 实际 PIE 中使用运行中的动画回调完成 A/A 一档、A/B 四档两局，展开、交付、回看、返回完成页均成功。读取动态材质参数，验证款式、深度与共享结果一致，展开恢复 108×76 厘米布面。
- 随后逐个使用鼠标点击清洗、沥水、先左后右松夹、展开、交付、回看、返回与重开。每段进行时按钮禁用，清洗后才开放沥水，单侧松开时展开仍禁用；重开后左右均未选择，演示物隐藏，A/B/C 恢复。
