# Content 文件管理结构说明

本文档约定 `LanRan/Content/` 下的资源组织方式。所有成员新增文件前请先确认目录归属，避免出现"随手丢进根目录"或多人各自建一套文件夹的情况。

## 一、组织原则

1. **按功能分层，而不是按人分层。** 目录代表资源在项目中的用途，`00_Core` 到 `09_Assets` 依次对应"底层框架 → 角色 → 环境 → 玩法 → 表现 → 素材"。
2. **数字前缀固定顺序。** 前缀只用于排序与辨认，重命名目录时不要改动编号，否则会影响所有成员的引用与习惯。
3. **原始素材与成品资源分开。** `09_Assets` 只放未经加工的外部导入资源和 AI 生成模型，处理完成后的资源再迁移到对应功能目录（待议）。
4. **资产必须有归属。** 如果一个文件同时符合多个目录，以"最终被谁引用"为准，而不是以它的文件类型为准。
5. **大文件走 Git LFS。** 模型、贴图、音频等二进制资源提交前请确认已由 Git LFS 接管。
6. **补充说明** 可根据个人需要新建分类或子文件夹，提交时务必提供说明清楚。

## 二、目录总览

```
Content/
├── 00_Core/          # 核心框架、GameMode、PlayerController
├── 01_Characters/    # 角色相关
├── 02_Environment/   # 场景环境
├── 03_Gameplay/      # 玩法逻辑
├── 04_Audio/         # 音频
├── 05_VFX/           # 特效（如果需要）
├── 06_Materials/     # 材质与贴图
├── 07_Blueprints/    # 通用蓝图工具
├── 08_Maps/          # 关卡地图
└── 09_Assets/        # 外部导入的原始资产
```

## 三、各目录职责

| 目录 | 存放内容 | 说明 |
| --- | --- | --- |
| `00_Core` | GameMode、PlayerController、GameInstance、全局配置类 | 项目最底层的框架代码与蓝图，其他模块都依赖它，尽量保持精简稳定 |
| `01_Characters` | 角色蓝图、动画蓝图、骨骼与动画资源 | 
| `02_Environment` | 场景搭建所需的静态资源 | 包括建筑、植被等 |
| `03_Gameplay` | 玩法逻辑资产 | 下分物品、UI等，根据需求新建子文件夹 |
| `04_Audio` | 音效、音乐、音源与相关资产 | 包括环境音、UI 音效等 |
| `05_VFX` | 粒子与特效资产 | 有特效需求再议 |
| `06_Materials` | 材质、材质实例与贴图 | 材质与其所用贴图放在一起，便于跟随引用关系查找 |
| `07_Blueprints` | 通用蓝图工具与可复用组件 | 不属于具体角色或玩法模块的工具型蓝图，例如示例中的 `BP_SkySphere` |
| `08_Maps` | 关卡地图 | 测试关卡统一放 `TestMaps/` 子目录，正式关卡放本目录 |
| `09_Assets` | 外部导入的原始资产 | 作为"素材仓库" |


### 使用规则

- **只进不出，不直接引用。** 关卡与蓝图不要直接引用 `09_Assets` 中的文件，避免后续替换素材时牵动大量引用。
- **先加工，后迁移。** 导入 UE 后完成清理、重命名、材质与碰撞调整，再迁移到对应的功能目录。
- **保留来源信息。** 建议在每个素材子目录内附一个说明文件，记录来源链接、授权协议、生成工具与提示词，方便后续溯源与合规检查（待议）。
- **按来源二次分目录。** 建议以"来源 + 批次"细分，例如 `09_Assets/AI_Character_01/`，避免所有文件平铺。
- **注意授权。** 外部素材与 AI 生成内容需确认可商用，且不要提交体积过大的中间文件到仓库。

## 四、命名规范

文件夹与资产统一使用英文，单词之间用下划线连接，不使用空格和中文。资源名建议带类型前缀，便于在内容浏览器中筛选：
（不必严格遵守，但请保持基本规范，方便阅读与查找）

| 前缀 | 含义 | 示例 |
| --- | --- | --- |
| `BP_` | 蓝图类 | `BP_Player` |
| `SM_` | 静态网格体 | `SM_Wall_01` |
| `SK_` | 骨骼网格体 | `SK_Enemy_01` |
| `M_` / `MI_` | 材质 / 材质实例 | `M_Rock`、`MI_Rock_Wet` |
| `T_` | 贴图 | `T_Rock_BaseColor` |
| `A_` | 动画序列 | `A_Run_Fwd` |
| `NS_` | 粒子系统 | `NS_Impact_Fire` |
| `S_` / `SC_` | 音效 / 声音提示 | `S_Footstep` |

## 五、现状与迁移说明

当前仓库中的 `Content/` 目录尚未使用数字前缀（例如现有的 `Core`、`Characters`、`Environment` 等）。
若需要迁移资产请保证规范，及时重定向，清理残留，同步更新本文档与根目录 `README.md` 中的说明。

在此之前，新增资源请按本文档定义的功能归属放入对应目录，避免结构与文档进一步脱节。
